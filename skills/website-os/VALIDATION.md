# Website OS validation

This package contains the generic skill, editor controls and local runtime. No author's website, project history or generated media is included. The surrounding Agentic OS connection screen opens on an empty localhost field. A URL connects a preview; source editing needs the one-time agent setup described in references/06-existing-homepage.md.

Generation provider: OpenArt. Image model: Nano Banana 2 (`nano-banana-2`) at the provider's 1K default. Video model: Seedance 2 Fast (`byte-plus-seedance-2-fast`) at 720p. Generated alternatives require review and a separate Save changes. Source-editing model is selected in the OS chat and is not hardcoded by this skill.

See the [release checks](../../RELEASE-CHECK.md) for the checks actually performed against this archive and the independent Claude review status.
