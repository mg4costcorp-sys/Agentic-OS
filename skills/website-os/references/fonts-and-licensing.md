# Fonts and asset provenance

Record the name, designer or foundry, source and licence for any font file you actually ship. Keep its licence beside the asset. Verify permission for the intended use from the current source when acquiring a new font. A design-reference page is not a licence grant.

The optional new-build assets include `templates/assets/ArchivoBlack.ttf` from the user-supplied Four Systems archive, together with its original `OFL.txt`. The workspace defaults to local system sans-serif and monospace stacks, so no additional font files are redistributed.

If a chosen reference uses a commercial font, use a user-licensed copy or select an appropriate alternative. Do not download it from a third-party mirror solely because a reference names it.

When using a font's italic face, load that face if available instead of relying on synthetic italics. When self-hosting, verify that the browser resolves the actual font file and retain a readable fallback.

Record icon pack and image sources too. Recolouring or cropping an asset does not change its licence. Company marks in a proof row should represent real, authorized relationships. Keep fictional demonstrations labelled as demonstrations and do not add customer logos or ratings to make an example look established.
