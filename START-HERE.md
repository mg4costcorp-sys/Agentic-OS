# Agentic OS 3.5: Start here

Read [README.md](README.md) for the complete first-run guide.

Install Bun, open this folder in your terminal and run:

```sh
bun install --frozen-lockfile
bun run dev
```

Open the printed local address, click **Website OS** in the bottom-left sidebar, and connect your own running localhost website. **Enable editing** prepares the one-time source integration request for your connected agent. A URL alone is a preview connection.

No personal demo is included. Images use OpenArt / Nano Banana 2 (1K default); video uses OpenArt / Seedance 2 Fast (720p), with your own credits.
